# Re-dice デザインシステム

「いつも一定だから、何も考えずに進める」を実現するための規約。
新しい UI を作るときは必ずここのトークンとルールに従う。
迷ったら **新しい値を作らず、既存のトークンから選ぶ**。

実装の実体は `src/styles.css` 冒頭の `:root` カスタムプロパティ。

---

## 1. ブランドアイデンティティ

コンセプト: **「晴れた海辺で開く卓」** — ロゴ(ヤシの木・太陽・波・サイコロ)由来。
明るく軽やかなマーケット(昼)と、没入するセッション(夜)の二面性を持つ。

| 色 | 変数 | 役割 |
|---|---|---|
| スカイブルー `#37ace8` | `--primary` | ブランドの主役。CTA・選択状態・リンク |
| ディープブルー | `--primary-deep` | 見出し・アイコン・強調テキスト |
| コーラル `#f0876b` | `--coral` | ロゴ「パラ」。危険ではない暖色アクセント |
| ミント `#7de4d3` | `--mint-*` | 成功・所持済み・ポジティブ |
| ゴールド `#f4c94a` | `--gold-*` | 注意喚起・注記(エラーではない) |
| 赤系 `#b91c1c` | (ad hoc) | 破壊的操作・失敗のみ。多用しない |

**ルール**
- 1 画面に **プライマリ CTA(`.btn-primary`)は原則 1 つ**。それ以外は `.btn` / `.btn.mini`。
- 赤は「削除・失敗」専用。目立たせたいだけなら primary を使う。
- グラデーションは `--grad-primary` / `--grad-accent` の 2 つだけ。

## 2. テーマ

- ライト(既定)とダーク(`html[data-theme="dark"]`)。**色は必ず変数経由**で書く
  (変数を使っていれば自動で両対応になる)。
- **PLAY(卓・ネット参加)中は強制ダーク**(没入優先)。実装は `App.tsx`。
- 生の hex を書いてよいのは、両テーマで共通にしたい色
  (画像上のオーバーレイ文字 `#fff` 等)だけ。

## 3. タイポグラフィ

- フォント: **Noto Sans JP**(`@fontsource` で同梱。CDN 不可)。
- ウェイトは 400 / 500 / 700 / 800-900 の 4 段。
  - 本文 400-500、ボタン 500-700、見出し 700、ブランド・数値強調 800-900。
- 薄く見せたいときは `--text-muted` → `--text-faint` の 2 段だけを使う
  (それ以上薄い色を発明しない。コントラストが死ぬ)。

## 4. 余白・角丸

- 余白は **4px の倍数**(4 / 8 / 12 / 16 / 24 / 32)。奇数 px を発明しない。
- 角丸は 3 種のみ:
  - `--radius-sm`(10px): 入力・チップ・小要素
  - `--radius-md`(14px): カード・パネル・ボタン
  - `999px`: ピル(バッジ・トースト・スクロールバー)

## 5. モーション(最重要)

**値は 3 つ + イージング 1 つだけ。** 新しい duration を書いたらレビューで弾く。

| トークン | 値 | 用途 |
|---|---|---|
| `--dur-1` | 0.12s | マイクロ: 色・不透明度のホバー |
| `--dur-2` | 0.18s | 標準: カードの浮き、チップ、フェード |
| `--dur-3` | 0.26s | 大きい面: ドロワー、トースト、画像差し替え |
| `--ease-out` | cubic-bezier(0.22, 1, 0.36, 1) | 全部これ |

**統一された振る舞い**(styles.css「共通挙動レイヤー」が保証):
- カードは hover で `translateY(-2px)` + 影、押すと `scale(0.99)`。全カード共通。
- ボタンは押すと 1px 沈む。無効時は `opacity: 0.55`。
- キーボードフォーカスは全要素同じリング(`--ring`)。
- `prefers-reduced-motion` でアニメーションは自動停止する。

## 6. 重なり順(z-index)

**必ず `--z-*` トークンから使う。数字を直書きしない。**

```
--z-fx(58) テロップ/カットイン < --z-dice(60) < --z-menu(64) 右クリック
< --z-pop(70) ポップオーバー < --z-drawer(80) ☰ < --z-viewer(85)
< --z-modal(90) 設定 < --z-toast(95) < --z-max(100)
```

ローカルな重なり(カード内バッジ等)は 1〜40 を自由に使ってよい。

## 7. アイコン

- マーケット側(ストア/ライブラリ/シェル)は **lucide-react**。
  サイズは 14(文中・ボタン) / 16(見出し) / 20(大見出し)の 3 段。
- アイコン+テキストの整列は `.ibtn` クラス(inline-flex / gap 6px)。
- PLAY 画面は当面絵文字を許容(暫定。置換するときは一括で)。

## 8. フィードバック

- 操作の成功は **トースト**(`toast("✓ …")` / `src/Toasts.tsx`)。silent success 禁止。
- 読み込みは **スケルトン**(`src/Skeleton.tsx`)。「読み込み中…」テキスト禁止。
- 失敗はその場の `.tag.fail`(赤)で理由を書く。

## 9. しないことリスト

- ❌ 新しい色・duration・z-index・フォントサイズ階層を「その場で」発明する
- ❌ `transition: all`(性能とバグの元)
- ❌ 1 画面に primary ボタンを並べる
- ❌ 変数を経由しない色指定(ダークテーマが壊れる)
- ❌ テキストだけの「読み込み中…」「保存しました」
