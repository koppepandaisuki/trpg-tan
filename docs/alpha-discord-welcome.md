# α テスター用 Discord 公式テンプレ集

α 期間中の Discord 運用で使う、公式版コピペテンプレ。Discord サーバーのチャネル設定・ピン留め投稿・招待 DM をここに集約する。Phase 2(β / 正式リリース)で内容を更新する。

---

## サーバーのチャネル構成(推奨)

| チャネル | 用途 | ピン留め投稿 |
|---|---|---|
| `#welcome` | サーバーに入った人がまず見る挨拶 | 「Welcome 投稿」(下記) |
| `#announcements` | 運営からのお知らせ(招待コード、メンテ、新機能) | (運営告知の都度) |
| `#feedback` | 感想・要望・全般フィードバック(💬 ボタンの送信先) | 「報告テンプレ」(下記) |
| `#bug-reports` | 深刻なバグの集中報告(混ぜたければ feedback に統合可) | 「バグ報告テンプレ」(下記) |
| `#purchase-test` | 購入動線の実況(α で重要) | 「購入テスト手順」(下記) |
| `#creator-help` | creator 向けサポート(ビルダー / Stripe 接続) | 「creator のはじめ方」(下記) |
| `#general` | 雑談・自己紹介 | (なし) |

## 購入テスト手順(`#purchase-test` ピン留め用)

```markdown
# テスト購入の手順

⚠ Stripe は **Test mode** で動作しています。実カードは使わないでください。

## 1. 商品を選ぶ
- `/store` から商品 1 件を選ぶ(無料商品でも有料商品でも OK)
- ¥0 の無料商品は購入動線が別(α では「準備中」表示)

## 2. 「今すぐ購入」をクリック
- ログインしていなければ /login にリダイレクトされます

## 3. Stripe Checkout で決済
- カード番号:`4242 4242 4242 4242`
- 有効期限:任意の将来日付(例:`12/30`)
- セキュリティコード:任意の 3 桁(例:`123`)
- 名義・郵便番号:適当でOK

## 4. 戻ってきたら確認
- `/checkout/success` に遷移すれば成功
- 数秒待って `/library` を開く → 購入した商品が表示される
- 「ダウンロード」ボタンが押せれば全工程成功 ✅

## 詰まったら
- そのままスクショ撮って `#bug-reports` か 💬 ボタンで送信
- 「どこで止まったか」が分かれば最高
```

## creator のはじめ方(`#creator-help` ピン留め用)

```markdown
# creator として商品を出す手順

⚠ α 期間中、サインアップしただけで自動的に creator 権限が付与されています。
(運営が手動で付与する手間を省くため。Phase 2 で申請 UI を実装予定)

## 1. ビルダーを開く
- `/creator/products/new` をクリック
- または TopHeader の「作成する」

## 2. 必須情報を入れる
- タイトル / 説明 / カテゴリ / 価格 / ファイル形式 / タグ

## 3. 価格を決める
- **無料(¥0)**:Stripe 接続未完了でも公開可(α 期間中の特例)
- **有料(¥100 以上)**:Stripe 接続(受取口座設定)が必要

## 4. 表紙画像とファイルをアップロード
- 表紙:PNG / JPG / WebP(10 MB 以下)
- 本体:カテゴリに応じた形式(PDF / 画像 ZIP / 音声)

## 5. 「公開して保存」
- エラーが出たら出た内容を `#bug-reports` か 💬 で報告

---

## Stripe 接続(有料販売したい人だけ)

- TopHeader 右側に「⚠ Stripe 未接続」と出ていればクリック
- `/creator/onboarding` で「Stripe 接続を開始」
- Stripe Express の onboarding 画面に飛び、本人確認 + 口座情報入力
- ⚠ **α 期間中は本物の身分証は使わないでください**(Stripe Test mode は実物確認しない設計)
- 本人確認の写真認識で詰まったら、α 中は **無料公開** で進めて OK

---

## 詰まったら

- `#creator-help` に投稿
- または画面右下の 💬 ボタン
```

## 運用 Tips

### 招待リンクの発行

1. Discord サーバー → サーバー名横の ▼ → 「サーバーへの招待」
2. 編集 → 期限「永久」または「30 日」/ 最大使用回数「お任せ」
3. 「新しいリンクを生成」→ コピー

### 投稿テンプレの貼り方

- 各チャネルの「チャネル設定」→ ピン留めしたい投稿の三点リーダー → 「メッセージをピン留め」
- バグ報告テンプレ等は、最初の投稿として書き込み → ピン留めで OK

### α 終了時の後処理

- `#announcements` で α 終了 + 御礼を投稿
- データリセットの有無を明示
- Phase 2 / β 開始時期を伝える(または「未定」と正直に)
- サーバーは保持(β でも同じサーバーを引き続き使用)
